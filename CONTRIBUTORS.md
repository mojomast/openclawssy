# Contributors

Openclawssy is a built-in-public Ussyverse project.

## How to contribute

If you want to contribute code, docs, testing, or design feedback:

1. Read [`CONTRIBUTING.md`](CONTRIBUTING.md)
2. Pick an issue or propose a scoped improvement
3. Open a PR with validation notes

## What contributions help most

- Runtime safety and policy hardening
- Dashboard UX and accessibility improvements
- Tool reliability and error handling
- Docs that improve onboarding and operational clarity
- Test coverage for regressions and production flows

## Recognition

Contributors are recognized through GitHub commit history, PR history, and the repository contributors graph.

Thank you for helping make Openclawssy more useful, safer, and more Ussycoded.
